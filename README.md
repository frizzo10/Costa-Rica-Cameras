# myDrSage — Vision Site

Repurposed from an earlier, unrelated Costa Rica cameras scaffold (old
content removed, still recoverable via git history if ever needed).

This is a single-page static site with three real jobs:

1. **Showcase the ring** — honestly. What it measures live today vs.
   what's hardware-capable but not wired up yet.
2. **Introduce the team** — Dr. Sage and the four specialists, in
   their own real voice, matching the app's actual design system.
3. **Document the guiding principles** — the real constraints that
   have shaped every feature decision in the myDrSage app so far.
   Meant to be referenced (and updated) as the app keeps growing,
   not a one-time mission statement.

Deploys to: airingwebsite.netlify.app

No build step — `index.html` is served as-is.
